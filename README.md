# GalliMall 🛒

**GalliMall** is a hyperlocal marketplace platform designed to bring neighborhood vendors and customers together. Built using **Django (backend)** and **Next.js (frontend)**, GalliMall empowers small vendors to create digital stores and enables customers to browse, shop, and order from nearby shops with ease.

---

## 🚀 Features

- 🛍️ **Customer Features**:
  - Browse categories and subcategories
  - View local shops and their products
  - Add to cart and order with Razorpay or PhonePe
  - "Click & Collect" option: ask vendors to pack items for pickup

- 🧑‍💼 **Vendor Features**:
  - Register & manage a digital store
  - Upload product images via Cloudinary
  - View and manage orders, earnings, and stock

- 🗺️ **Location Based**:
  - Detect and show nearest vendors
  - Shop filtering by location and categories

---

## 🛠️ Tech Stack

| Layer     | Tech                          |
|-----------|-------------------------------|
| Frontend  | Next.js + Redux Toolkit       |
| Backend   | Django + Django REST Framework |
| Auth      | JWT Authentication (Simple JWT) |
| Payments  | Razorpay + PhonePe (manual entry) |
| Media     | Cloudinary (for product images) |
| Database  | SQLite / PostgreSQL           |
